# Engine

픽셀 그래픽 2D 게임을 만드는 작은 자체 엔진과, Godot처럼 생긴 에디터예요.
첫 목표는 「창가석 기차 여행」 같은 가벼운 게임(창밖 풍경이 겹겹이 흐르고, 시간대에 따라 빛이 바뀌는 게임)을 이 엔진으로 만드는 거예요.

![에디터 화면](docs/editor.png)

## 실행하기

1. [Node.js](https://nodejs.org/) LTS 버전을 설치해요. (한 번만)
2. 이 저장소를 내려받은 폴더에서 터미널을 열고:
   ```
   npm install
   npm run editor
   ```
   윈도우라면 `start-editor.bat`을 두 번 눌러도 돼요. (처음 한 번은 `npm install`도 알아서 해요.)
3. 브라우저에서 http://127.0.0.1:8710/ 을 열면 에디터가 나와요.

처음에는 `examples/train-window` 예제(메이링겐 → 인터라켄 창밖 풍경)가 열려요.
내 게임 폴더를 열려면 `npm run editor -- --project D:\내게임` 처럼 폴더를 알려 주면 돼요. 빈 폴더여도 괜찮아요.

## 에디터에서 할 수 있는 것

| 자리 | 하는 일 |
| --- | --- |
| 위 메뉴 | 씬 새로 만들기/열기/저장, 실행 취소, 프로젝트 설정, 웹으로 내보내기 |
| ▶ ▷ ■ | 메인 씬 실행(F5), 지금 씬 실행(F6), 정지(F8). 게임은 새 창에서 돌아요 |
| 왼쪽 위 「씬」 | 노드 트리. 추가(Ctrl+A), 이름 바꾸기(F2), 끌어서 순서/부모 바꾸기, 숨기기 |
| 왼쪽 아래 「파일시스템」 | 프로젝트 파일. 그림을 화면으로 끌면 Sprite2D가 생겨요 |
| 가운데 「2D」 | 화면 편집. 끌어서 옮기기, 가운데 버튼/Space+끌기로 화면 이동, 휠로 확대 |
| 가운데 「스크립트」 | 자바스크립트 편집기 (Ctrl+S 저장) |
| 오른쪽 「인스펙터」 | 고른 노드의 속성. 숫자 이름을 좌우로 끌면 값이 바뀌어요 |
| 아래 「출력」 | 게임과 에디터의 메시지 |
| 아래 「버전 관리」 | Git: 바뀐 파일, 비교, 커밋, 받기(pull), 올리기(push) |
| 아래 「AI」 | Claude Code 또는 Codex에게 일을 시키기 |

노드 종류: Node, Node2D, Sprite2D, ColorRect(그라데이션), Label, Parallax2D(시차 레이어), Camera2D, CanvasModulate(전체 색 곱하기 = 시간대 조명), CanvasLayer(화면에 고정된 UI).

## AI (Claude Code, Codex)

에디터의 AI 패널은 내 컴퓨터에 설치된 명령줄 도구를 불러요. 쓰려는 것 하나만 설치하면 돼요.

- Claude Code: `npm install -g @anthropic-ai/claude-code` 설치 후 터미널에서 `claude`를 한 번 실행해 로그인
- Codex: `npm install -g @openai/codex` 설치 후 `codex`를 한 번 실행해 로그인

모드는 두 가지예요.
- **질문만**: 파일을 고치지 않고 답만 해요.
- **수정 허용**: 프로젝트 폴더 안의 파일을 고칠 수 있어요. 끝나면 에디터가 바뀐 파일을 다시 읽어요. 고치기 전에 커밋해 두면 마음에 안 들 때 되돌리기 쉬워요.

답이 끝나면 걸린 시간과 쓴 토큰(Claude는 비용까지)이 패널에 나와요.

## 토큰을 아끼는 설계

- AI에게 보낼 때 엔진 요약표(`server/ai-context.md`, 한 쪽 분량)와 지금 열린 씬/고른 노드를 같이 보내요. AI가 파일을 뒤지며 엔진을 파악하느라 토큰을 쓰지 않아요.
- 「이어서 대화」를 켜면 앞 대화를 이어 가서 같은 설명을 반복하지 않아요.
- 씬 파일은 기본값과 다른 속성만 적고, 짧은 값은 한 줄에 써요. AI가 읽는 양이 적어요.
- 엔진 저장소 자체를 고칠 때는 `AGENTS.md`(구조 지도)를 먼저 읽게 되어 있어서, 필요한 파일만 열어요. 파일도 기능별로 작게 나눠 두었어요.

## 웹과 스팀

- 게임은 자바스크립트(브라우저의 Canvas 2D)로 돌아가요. 에디터의 「프로젝트 → 웹으로 내보내기」를 누르면 프로젝트 안 `export/web` 폴더에 웹사이트용 파일이 생겨요. itch.io 같은 곳에 그대로 올릴 수 있어요.
- 스팀용은 같은 웹 빌드를 Electron(또는 Tauri)으로 감싸서 윈도우/맥 실행 파일로 만들고, 업적 같은 스팀 기능은 steamworks.js로 붙이는 방식이 계획이에요. 아직 만들지 않았어요.

## 개발용 명령

```
npm run dev        # 에디터 코드를 고치면 바로 반영되는 개발 모드
npm run check      # 타입 검사 + 단위 테스트
npm run test:e2e   # 브라우저로 에디터를 직접 조작하는 테스트
npm run export:web -- <프로젝트 폴더>
```
