# 편집 도구 사용법

`start.bat`(맥은 `start.sh`)으로 연 화면에서만 켜져요. 내보낸 게임(`game.html`)에는 들어가지 않아요.

창이 여러 패널로 나뉘어 있어요: **오브젝트 목록**, **장면 보기**, **인스펙터**, **장면**, **프로젝트**.
- 패널 위의 탭을 끌어서 다른 패널의 **가장자리**에 놓으면 그쪽으로 나뉘고, **가운데**에 놓으면 탭으로 합쳐져요. 파란 칸이 놓일 자리를 보여 줘요.
- 패널 사이 경계선을 끌면 크기가 바뀌어요. ✕로 닫은 패널은 위쪽 **+ 패널 열기**에서 다시 열어요.
- 배치는 이 브라우저에 기억되고, **패널 배치 처음대로**를 누르면 돌아가요.
- 편집하는 동안에는 배경 음악이 꺼지고, **▶ 플레이**를 누르면 장면만 크게 나오고 음악도 다시 나와요.

## 위쪽 줄
- **✎ 편집하기 / ▶ 플레이**: 게임을 멈추고 고치기 ↔ 지금 장면을 처음부터 해 보기
- **장면**: 고칠 장면 고르기.
- **↖ 고르기 · 옮기기**: 맵의 오브젝트를 클릭해 고르고, 끌어서 옮겨요. 안에 든 오브젝트도 같이 움직여요. 프리팹을 놓는 중이면 "놓는 중: coin"처럼 보이고, 누르거나 Esc로 고르기로 돌아가요.
- **격자**: 놓거나 옮길 때 몇 픽셀 단위로 맞출지.
- **?**: 마우스를 올리면 단축키가 나와요.
- **↶ 되돌리기** (Ctrl+Z), **저장** (Ctrl+S). 오른쪽 끝에 저장 안 된 파일 수가 보여요.

## 오브젝트 목록 패널
장면에 놓인 오브젝트가 전부 나와요 (아래에 있을수록 앞에 그려져요).
- 아이콘은 프로젝트 패널과 같아요: 그림 + 구석의 파란 상자 = 프리팹으로 만든 오브젝트, 점선 상자 = 빈 오브젝트, T = 글자 오브젝트.
- **여러 개 고르기**: Ctrl+클릭으로 하나씩 더하거나 빼고, Shift+클릭으로 사이의 줄을 한꺼번에 골라요. 맵에서도 Ctrl/Shift+클릭이 돼요.
  고른 것 중 하나를 맵에서 끌면 모두 같이 움직이고, 목록에서 끌면 모두 같이 옮겨져요. 복제(Ctrl+D)와 지우기(Delete)도 한꺼번에 돼요.
- **+ 오브젝트**: 빈 오브젝트 만들기. **+ 자식 오브젝트**: 고른 오브젝트 안에 만들기. 만든 다음 **오브젝트** 패널에서 프리팹을 골라요.
- 오브젝트를 끌어 다른 오브젝트 **위**에 놓으면 그 안으로 들어가고, 오브젝트 **사이**에 놓으면 순서가 바뀌어요. 목록 아래 빈 곳에 놓으면 밖으로 나와요.
- ▾/▸로 안에 든 오브젝트를 접고 펴요.

## 프로젝트 패널
게임을 이루는 파일을 윈도우 탐색기처럼 보여 줘요 (유니티의 프로젝트 창).
- 왼쪽은 폴더: `assets`(그림), `assets/sounds`(소리), `prefabs`(src/kinds.json 안의 프리팹), `scenes`(장면). 두 번 클릭하면 폴더로 들어가고, 위쪽 ↑로 나와요.
- 위쪽 **모든 형식** 목록으로 프리팹, 그림, 소리, 장면만 골라 볼 수 있어요. 형식을 고르거나 이름을 찾으면 아래 폴더까지 모두 뒤져요.
- **☰ 자세히 보기**는 이름, 형식, 정보(크기, 길이, 컴포넌트 수)를 한 줄씩 보여 주고, 제목을 누르면 그 순서로 정렬돼요. **▦ 큰 아이콘 보기**는 그림을 크게 보여 줘요.
- 형식마다 아이콘이 달라요: 파란 상자 = 프리팹, 초록 액자 = 그림, 주황 스피커 = 소리, 보라 슬레이트 = 장면, 노란 폴더 = 폴더.
- **클릭**: 인스펙터에서 보기. **두 번 클릭**: 프리팹은 맵을 클릭할 때마다 놓기, 소리는 들어 보기, 장면은 열기.
- **끌기**: 프리팹이나 그림을 장면 보기에 놓으면 오브젝트가 생겨요. 그림이면 같은 이름의 프리팹을 만들어(이미 있으면 그대로 써서) 놓아요.
- `prefabs` 폴더 아래 칸에서 새 프리팹, `scenes` 폴더 아래 칸에서 새 장면(바닥과 플레이어가 놓인 채로)을 만들어요.

## 인스펙터 / 장면 패널
- **인스펙터**: 마지막으로 고른 것의 세부 사항이 나와요 (유니티의 인스펙터).
  - 맵이나 오브젝트 목록에서 고른 **오브젝트**: 이름, 프리팹(빈 오브젝트 가능), 위치(안에 든 오브젝트는 부모 기준), 크기(w/h), 이 오브젝트만 다르게 할 값. 복제(Ctrl+D), 지우기(Delete, 안에 든 것까지). **프리팹 고치기**를 누르면 그 프리팹이 나와요.
  - **프리팹**: 그림, 애니메이션, 컴포넌트. 컴포넌트를 더하고(맨 아래 목록), 순서를 ↑↓로 바꾸고, ✕로 빼요. 값을 바꾸면 그 프리팹으로 만든 오브젝트가 모두 바뀌어요.
  - **그림**: 크게 보기, 크기, 이 그림을 쓰는 프리팹, 이 그림으로 프리팹 만들기.
  - **소리**: 길이, 들어 보기, 이 소리를 쓰는 곳.
  - **장면**: 맵 크기, 오브젝트 수, 배경 음악, 다음 장면, 이 장면 열기.
- **장면**: 지금 열린 장면의 맵 크기, 하늘색, 배경 음악, 다음 장면, 규칙(모을 프리팹, 제한 시간). 화면 글자는 `text` 프리팹으로 놓는 오브젝트예요.

## 맵 움직이기
방향키, 마우스 휠(Shift+휠은 위아래), 오른쪽 버튼으로 끌기.

## 저장하면
`src/kinds.json`과 바뀐 `src/scenes/*.json` 파일이 사람이 쓴 모양 그대로 고쳐져요. 그래서 GitHub Desktop에서 무엇이 바뀌었는지 한눈에 보여요.
저장하지 않고 창을 닫으려 하면 한 번 물어봐요. 문구나 소리 같은 규칙 값은 아직 `src/modules/rules/rules.json`에서 직접 바꿔요.
