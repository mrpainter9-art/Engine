# 편집 도구 사용법

`start.bat`(맥은 `start.sh`)으로 연 화면에서만 켜져요. 내보낸 게임(`game.html`)에는 들어가지 않아요.

장면이 창 전체에 크게 보이고, 패널 두 개(**놓을 물건**, **고치기**)가 그 위에 떠 있어요.
- 패널 제목줄을 끌면 옮겨지고, 오른쪽 아래 모서리를 끌면 크기가 바뀌어요. ▾로 접어 둘 수 있어요.
- 위치와 크기는 이 브라우저에 기억돼요. 위쪽 **패널 제자리로**를 누르면 처음 자리로 돌아가요.
- 편집하는 동안에는 배경 음악이 꺼지고, **▶ 플레이**를 누르면 다시 나와요.

## 위쪽 줄
- **✎ 편집하기 / ▶ 플레이**: 게임을 멈추고 고치기 ↔ 지금 장면을 처음부터 해 보기
- **장면**: 고칠 장면 고르기. 옆 칸에 이름을 적고 Enter를 누르면 새 장면이 생겨요 (바닥과 플레이어가 놓인 채로).
- **↶ 되돌리기** (Ctrl+Z), **저장** (Ctrl+S). 오른쪽 끝에 저장 안 된 파일 수가 보여요.

## 놓을 물건 패널
- **고르기 · 옮기기**: 맵의 물건을 클릭해 고르고, 끌어서 옮겨요.
- 종류를 고르고 맵을 클릭하면 그 자리에 놓여요. 계속 클릭하면 여러 개. Esc로 고르기 도구로 돌아가요.
- 맨 아래 칸에 이름을 적고 Enter: 새 종류 만들기. **격자 칸**: 놓을 때 몇 픽셀 단위로 맞출지.

## 고치기 패널: 세 가지 탭
- **물건**: 고른 물건 하나의 위치, 크기(w/h, 그림보다 크면 반복), 이 물건만 다르게 할 값. 복제(Ctrl+D), 지우기(Delete).
- **종류**: 그림, 애니메이션, 행동 블록. 블록을 더하고(맨 아래 목록), 순서를 ↑↓로 바꾸고, ✕로 빼요. 값을 바꾸면 그 종류 모두가 바뀌어요.
- **장면**: 맵 크기, 하늘색, 배경 음악, 다음 장면, 규칙(모을 종류, 제한 시간), 화면 글자.

## 맵 움직이기
방향키, 마우스 휠(Shift+휠은 위아래), 오른쪽 버튼으로 끌기.

## 저장하면
`src/kinds.json`과 바뀐 `src/scenes/*.json` 파일이 사람이 쓴 모양 그대로 고쳐져요. 그래서 GitHub Desktop에서 무엇이 바뀌었는지 한눈에 보여요.
저장하지 않고 창을 닫으려 하면 한 번 물어봐요. 문구나 소리 같은 규칙 값은 아직 `src/modules/rules/rules.json`에서 직접 바꿔요.
