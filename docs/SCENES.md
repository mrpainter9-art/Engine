# 장면 파일

`src/scenes/` 폴더의 JSON 파일 하나가 장면 하나예요 (타이틀, 스테이지...). 파일 이름이 장면 이름이에요 (`stage1.json` → `stage1`).
게임은 `settings.json`의 `firstScene` 장면부터 시작해요.

| 항목 | 하는 일 | 예 |
| --- | --- | --- |
| `size` | 맵 크기(픽셀). 없으면 화면 한 장 | `{ "width": 960, "height": 180 }` |
| `background` | 하늘색. 없으면 `modules/background/background.json`의 색 | `"#f6b26b"` |
| `music` | 반복되는 배경 음악 (`assets/sounds`의 이름). 다음 장면도 같은 곡이면 끊기지 않아요. 편집 중에는 꺼져요 | `"song"` |
| `rules` | 이 장면의 게임 규칙. `rules.json`의 값 중 바꿀 것만 적어요. **없으면 메뉴 장면**(스페이스를 누르면 `next`로) | `{ "timeLimit": 50 }` |
| `next` | 클리어하고 스페이스를 누르면 갈 장면. 없으면 같은 장면을 다시 | `"stage2"` |
| `objects` | 오브젝트 목록: 프리팹, 위치, 그 오브젝트만 바꿀 값, 크게 놓을 `w`/`h`, 이름(`name`), 안에 든 오브젝트(`children`) | `{ "kind": "slime", "x": 360, "y": 148, "speed": 50 }` |

## 오브젝트
장면에 놓인 것 하나하나가 오브젝트예요. 오브젝트마다 프리팹(`kind`)을 골라요. 프리팹이 `""`이면 그림 없는 **빈 오브젝트**로, 다른 오브젝트를 묶는 데 써요.
오브젝트 안에 오브젝트를 넣을 수 있어요(`children`). 안에 든 오브젝트의 위치는 부모 기준이고, 게임 중에 부모가 움직이면 같이 움직여요.
```json
{ "name": "슬라임 기사", "kind": "slime", "x": 400, "y": 148, "children": [
  { "kind": "coin", "x": 4, "y": -12 }
] }
```

흐름: 클리어 → 스페이스 → `next` 장면. 시간 초과 → 스페이스 → 같은 장면 처음부터.
새 스테이지는 기존 파일을 복사해서 이름만 바꾸고, 앞 장면의 `next`를 새 이름으로 바꾸면 이어져요.

## 화면 글자
글자도 오브젝트예요. `text` 프리팹을 놓고, 그 오브젝트만 바꿀 값으로 내용과 모양을 정해요.
`screen`이 true(기본)면 x, y는 화면 기준이라 카메라가 움직여도 그 자리에 있어요.
```json
{ "kind": "text", "name": "제목", "x": 160, "y": 30, "text": "작은 엔진", "align": "center", "color": "#f2c14e", "scale": 2 }
```

## 저장 (최고 기록)
클리어하면 그 장면의 최고 기록(남은 초, 제한 시간이 없으면 점수)을 브라우저에 저장해요. 창을 닫아도 남아요.
- 규칙 문구에서 `{best}`는 이 장면의 최고 기록, 기록을 넘으면 `recordText`("새 기록!")가 떠요.
- 글자 오브젝트(`text` 프리팹)에서는 `{best-stage1}`처럼 장면 이름을 붙여서 어느 장면의 기록이든 보여 줄 수 있어요.
- 저장 서랍 이름은 `settings.json`의 `saveName`. 게임마다 다르게 하면 기록이 섞이지 않아요.
- 저장은 그 브라우저에만 돼요. 다른 컴퓨터나 시크릿 창에서는 기록이 없어요.
